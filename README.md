
# fullstack_developer_capstone

## Cars Dealership — Full Stack Web Application

This project is a full-stack car dealership review application developed as part of the IBM Full Stack Software Developer Professional Certificate.

The application allows users to browse car dealerships, filter dealerships by state, view dealership details, and read customer reviews. It also supports authenticated review submissions and sentiment analysis.

### Technologies
- React, JavaScript, HTML, and CSS
- Python and Django
- Node.js and Express
- MongoDB and SQLite
- Docker
- IBM Cloud Code Engine
- Git and GitHub

### Features
- Dealership directory
- State-based dealership filtering
- Individual dealership details
- Customer reviews
- User authentication
- Review sentiment analysis
